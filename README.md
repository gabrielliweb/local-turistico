# 🌏 Local Turístico

Projeto desenvolvido como desafio do módulo de **HTML e CSS** da formação Frontend da Rocketseat. A proposta foi criar uma página de divulgação de um destino turístico, aplicando boas práticas de HTML semântico e estilização com CSS puro.

## 📖 Sobre o desafio

O objetivo era construir uma página que apresentasse um local turístico, contendo:

- Header com título de destaque;
- Seção de introdução com imagem principal e legenda;
- Seção com pelo menos 3 atrações do local, cada uma com imagem, título, descrição e link "Saiba mais";
- Estilização completa com cores, tipografia, espaçamentos e bordas arredondadas seguindo um layout de referência;
- Rodapé simples e centralizado.

Cidade escolhida: **Busan, Coreia do Sul** 🇰🇷

## 🚀 Tecnologias utilizadas

- HTML5 (semântico)
- CSS3

## ✨ Funcionalidades / requisitos atendidos

- [x] Estrutura semântica com `header`, `section` e `footer`
- [x] Título principal e subtítulo de destaque
- [x] Imagem principal com legenda
- [x] Três atrações turísticas, cada uma com imagem, título, texto e link "Saiba mais"
- [x] Tags de categoria ("Bom para") com cores diferentes por categoria
- [x] Divider entre seções
- [x] Bordas arredondadas nas imagens
- [x] Rodapé centralizado com créditos

## 🎨 Layout

O layout seguiu como base o design de referência do desafio, com paleta de cores, tipografia (Open Sans e Alice) e espaçamentos definidos a partir do guia de estilos fornecido.
